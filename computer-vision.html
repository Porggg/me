Computer Vision Algorithms

My own implementation of basic computer vision algorithms in Python, using only NumPy for the maths and Pillow to read and write images.

  • Filters: 2D convolution, box and Gaussian blur, Sobel derivatives, derivative of Gaussian.
  • Edge detection: gradient magnitude and orientation, then non-maximum suppression along the gradient direction.
  • Harris corner detection: structure tensor, corner response, heatmap and thresholded corners.

Each function is unit tested with pytest, and the tests run on every push with GitHub Actions.
